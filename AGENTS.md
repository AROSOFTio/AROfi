# AROFi Agent Rules

## AROFI_NO_AUTOMATIC_MAC_AUTH

Automatic MikroTik HotSpot RADIUS MAC authentication is permanently forbidden in AROFi.

Never:
- add the exact `mac` token to any RouterOS HotSpot `login-by` value;
- add or restore `mac-auth-mode`;
- authenticate a newly connected phone with MAC-as-username/password;
- bypass the captive portal with a MAC/IP binding;
- replace the direct RouterOS voucher/payment/reconnect POST with an iframe or timer delay;
- add a local idle, keepalive or session timer that ends an otherwise active bundle.

The required HotSpot login mode is exactly:

```routeros
login-by=cookie,mac-cookie,http-pap
```

`mac-cookie` is required and is not the forbidden `mac` mode. RouterOS creates a trusted mac-cookie only after the customer successfully logs in with voucher/payment credentials. It allows that same device to reconnect automatically while access remains active. Do not remove it.

Every HotSpot user profile must preserve:

```routeros
shared-users=1 add-mac-cookie=yes mac-cookie-timeout=30d idle-timeout=none keepalive-timeout=none session-timeout=0s
```

Voucher, payment, recovery and active-return credentials must be submitted immediately to the router login endpoint with a top-level POST. A returning device with an ACTIVE, unexpired, matching MAC/router activation must auto-reconnect instead of showing “Action required.”

Allowed MAC uses are device identification, one-device package binding, trusted post-login mac-cookie reconnect, anti-sharing, accounting and explicit customer-initiated Smart TV provisioning. They must never trigger RADIUS authentication before a new customer sees the captive portal.

An active bundle may end only because of its real RADIUS/package expiry, data-quota exhaustion, or explicit authorized revocation. Missing heartbeat/accounting, screen lock, inactivity and temporary Wi-Fi sleep must never revoke access.

## AROFI_BUSINESS_VOUCHER_QR

Printed and previewed voucher QR codes must always use the exact MikroTik-local business hostname generated by the API:

```text
http://<business>.wifi/login?voucher=<URL-ENCODED-CODE>
```

Never:
- force a voucher QR to `10.55.0.1` or any other gateway IP;
- use `/login/voucher=...` without the required `?` query separator;
- route a printed voucher QR through the public `arofi.net` portal;
- let Admin preview, PDF generation and router DNS generate different business hostnames.

The API helper in `apps/api/src/common/tenant-hotspot-domain.ts` is the authoritative hostname/QR generator. The Admin preview must use the `hotspotDomain` returned by the API, not rebuild it independently.

A `.wifi` QR is intentionally local and works after the customer joins that venue's Wi-Fi. The MikroTik setup must advertise the router as DNS, set the HotSpot `dns-name`, add the matching static DNS record and flush DNS cache.

## AROFI_INSTANT_CAPTIVE_COMPLETION

Voucher, trial, recovery and Mobile Money success must finish in the current captive window:

- one immediate top-level POST to the RouterOS login URL;
- no gateway checkout redirect for MTN/Airtel STK/PIN payments;
- payment status polling starts immediately;
- no visible `Connected` page;
- `alogin.html` and `status.html` are invisible close/connectivity-check documents;
- no second button, manual tap, iframe or artificial success delay.

The RouterOS POST destination should be the original external captive probe when safe, otherwise an operating-system connectivity-check endpoint. Do not send successful customers back to `<business>.wifi/login?connected=1`.

Any change touching MikroTik onboarding, HotSpot profiles, captive login, Smart TV access, voucher QR, voucher reconnect, Mobile Money completion, accounting or portal redirects must preserve these rules and pass:

```bash
python3 scripts/enforce_business_voucher_qr.py
python3 scripts/verify_router_captive_invariants.py
python3 scripts/forbid_mikrotik_auto_mac_auth.py
```

Do not weaken, bypass, remove or rename these guards. Reversing a policy requires an explicit repository-owner instruction that specifically names the policy being reversed.
